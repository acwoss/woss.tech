# docs/

Material para quem escreve no site, não conteúdo publicado.

- **`modelo-publicacao.html`** — esqueleto comentado. Copie para
  `publicacoes/AAAA-MM-DD-slug.html` e escreva. Os comentários marcam o que é
  fixo e explicam as pegadinhas de cada componente.

As convenções completas estão no [`CLAUDE.md`](../CLAUDE.md) da raiz.

Esta pasta é bloqueada no `robots.txt` e o modelo tem `noindex`: ele é
alcançável pela URL, mas não deve aparecer em busca.
