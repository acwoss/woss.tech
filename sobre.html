Anderson Woss

Engenheiro de software. Passo os dias entre sistemas distribuídos que precisam continuar de pé e modelos de linguagem que precisam parar de inventar.

Este site é onde eu penso devagar. O trabalho me dá pressa; aqui eu escrevo o que só fica claro depois de medir, errar e medir de novo.

O que você vai achar aqui

Ensaios longos sobre engenharia de software e inteligência artificial aplicada — a segunda sempre pelo lado que dá trabalho: contrato de API, observabilidade, custo por requisição, teste que pega o bug antes do cliente, e o que acontece quando o sistema tem um componente que às vezes inventa.

Não vai achar thread de dez tweets sobre a revolução da IA, nem tutorial de framework da semana. Todo número citado vem com a consulta que o produziu; toda afirmação que se provou falsa é corrigida no próprio texto, com a data.

Como este site é feito

HTML, CSS e JavaScript escritos à mão, sem framework e sem CMS. Cada publicação é um arquivo .html, o que me deixa livre para dar a cada texto a forma que o assunto pedir. O código é aberto — tem um ensaio explicando as decisões, e o repositório está no GitHub.
